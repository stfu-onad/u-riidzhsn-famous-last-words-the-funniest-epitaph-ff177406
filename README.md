# Famous Last Words: The Funniest Epitaph

One line of famous last words, a tombstone epitaph: a polite man holds
the door for Death, and Death, being polite, lets him go first — so he is
still holding it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the line (single line, 1–150 characters, not blank)
and writes it plus a trailing newline to `/output/entry.txt`.
